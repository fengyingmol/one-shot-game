# 一发入魂 · 弹射小游戏

一个单手可玩的网页小游戏：拖动瞄准，松手开枪，用有限弹药、反弹和爆炸连锁清场。支持手机和电脑浏览器，包含十一关机制教学、三关渐进正式关卡，以及三关测试挑战。

## 游戏内容与 AI 修改入口

完整规则、子弹与怪物、平衡参数、关卡和代码位置记录在 [游戏内容说明.md](游戏内容说明.md)。AI 修改项目先读 [AGENTS.md](AGENTS.md) 和这份说明；每次规则变化同步更新说明。

局域网试玩（PowerShell）：`$env:ONE_SHOT_HOST='0.0.0.0'; node server.cjs`，手机连接同一 Wi-Fi 后打开 `http://电脑的局域网IPv4地址:4180`。IP 可能变化，请以当前 WLAN 地址为准；默认仍只监听本机。服务只开放游戏运行文件和图片 / 音频，不开放 Git、工具或浏览器配置。

在场地内拖动瞄准，松手开枪。每关只配发固定种类和数量的弹药，耗尽的弹种不能选。每一枪后保留怪物和地形的变化，自动进入下一枪；清场过关，用完弹药仍有怪则失败。R 重试整关，恢复弹药和场景。点击「关卡」展开选关，速度固定 800。音乐与音效默认开启，素材加载完毕后点击“进入游戏”启动播放，可手动关闭。

本地 UI 已更新为「玩具小院」：采用圆润卡通 3D 风格 PNG、小人持枪瞄准、柔和落地阴影，是 Canvas 2.5D 表现，弹道与碰撞仍保持原平面坐标。手机竖屏主界面一屏显示场地、分数、本关弹药和重试 / 关卡；关卡覆盖菜单中保留声音设置、教学 / 元素及成绩。主题在 `casual.css`，独立素材与生成记录见 [assets/toy-art.md](assets/toy-art.md)，无需运行时 CDN。

0.21既有玩法与表现：新增穿甲弹、前向渐展散弹、正式关「分弹拆局」、教学 / 正式 / 测试分区、默认正式入口、生成的半碎裂木箱素材、地形提示精简，以及射击画布缩放修复。既有画面：小人使用五个完整短臂持枪姿势，取消会伸长的独立袖子；帽子重新生成并缩小贴合圆头。盾牌直接放大为直径48的圆盘，绘制与碰撞共用同一几何范围，不再显示外围格挡弧；身体背后仍可击倒、爆炸仍绕盾。后续修改默认继续本地迭代。

手机高清优化：画布按显示尺寸和设备像素密度渲染（最高 3 倍密度），不改变物理坐标。手机文字和场地显示增大，发射 / 命中 / 得分增加轻量反馈；浏览器模拟 2x / 3x 手机画面及射击检查通过，实体手机性能仍需试玩。线上是否生效需核对部署结果。

不同房间采用 contain 等比适配：小关可留白、大关等比缩小，不裁掉玩法空间。新背景所有裁片按 `18/96` 倍率平铺 / 拼接，角色和地形同样等比绘制，宽高变化只增减铺设数量。12 房间与多种手机视口检查通过；小于 460px 高的横屏可能滚动。包含在0.13发布版本。

音乐与音效：默认开启，点击进入游戏即启动播放，右上角声音按钮可静音。原创《小院散步》为 96 BPM、40 秒轻松木琴 / 拨弦循环，14 种短音效区分射击、命中、反弹、护甲、地形、爆炸和胜负；「音乐与音效」面板可分别开关和调音量。切关不叠播，后台暂停，爆炸时音乐轻微避让。资源在 `assets/audio/`，用 `node make-audio.cjs` 可重建；`node audio-check.cjs` 验证音频。声音实现为 `soundtrack.js` + `audio.js`，随0.13一并提交。

上一枪轨迹默认隐藏。射击并重试后，可点击「查看上一枪轨迹」作为本次瞄准参考；每次重试恢复隐藏，切关清除轨迹。该按钮不是开关，不保留查看偏好。

每次有效命中 +10 分，同一枪内 1 个游戏秒内连续命中从第二次开始额外加 5、10、15……分；三连击合计 45 分。打掉头盔也计命中，盾牌挡弹和环境碰撞不加分。爆炸连锁击倒逐个计分。本关多枪累积分数，下一枪连击重新开始；重试整关清零，页面会话保留各关最高分。

三种内部地形：木色普通障碍物两次子弹命中或一次爆炸即可破坏；红褐色砖墙只能被爆炸破坏；蓝灰色铁墙不可破坏。未破坏时反弹，普通障碍物第二次命中后子弹直接穿过。爆炸弹碰到可破坏地形立即引爆并消失；破坏地形不加分、不续能，重试恢复。

采用 Canvas 图形，无外部依赖。每关独立房间大小：大部分教学关为宽 360–420、高 400–560，策略关 420 × 640；穿甲长路线与综合挑战保留 600 × 900。发射点和边界随房间改变。侧面和顶部反弹，底部开放，越过底部直接消失（爆炸弹落底也不引爆）。弹道保留 0.48 个游戏秒，基准速度 800，爆炸时短暂减速。

默认进入正式01「折返小院」，然后是02「错位回廊」、03「双庭回响」。原十一关教学顺序仍为穿透 → 铁墙反弹 → 头盔 → 破木障碍 → 爆炸开砖墙 → 盾牌背后 → 炸弹怪 → 桶连锁 → 穿甲长回程 → 散弹扇形覆盖 → 射击顺序。测试01「分弹拆局」480×680：10只怪、1桶、8段障碍，四种弹各1发；测试02为转向工坊；末关测试03「四区回廊」600×900：18只怪、4桶、三种地形，配发普通2发和其他三种弹各1发。各关独立成绩，刷新清空。

测试03「四区回廊」包含头盔怪和炸弹怪，各 4 只。头盔怪是戴金色头盔的普通怪：第一枪头盔翻滚掉落，不续能、不计击倒，子弹继续穿透；再次命中才击倒续能，爆炸可直接击倒。一次穿过不能连续扣两次生命，子弹离开后返回或另一颗弹丸命中才算下一枪。

炸弹怪为红色、带发光引线，一击死亡后产生半径 70 的小爆炸，计入清怪目标并续能；炸药桶不是怪物，不计清怪数，被子弹触碰或爆炸波及就引爆，半径 102。炸弹怪、炸药桶可以互相引爆，爆炸不伤害子弹。

瞄准前可选择四种子弹。动能比例为普通弹 1、穿甲弹 1.5、爆炸弹 0.8、散弹（每颗）0.5，比例与引擎实际能量分开配置。普通弹基础动能从旧版 2.4 降为 1.6，动能上限和命中续能也降低三分之一，再按弹种比例计算；飞行速度不变。

穿甲弹速度为普通弹的 1.5 倍，一击摧毁并穿透木障碍、一击击倒头盔怪，击倒只计一次命中并续能；砖墙、铁墙和盾牌仍反弹；爆炸弹首次命中目标时产生一次半径 64 像素的爆炸，未命中则在耗尽时引爆，爆炸后子弹立即消失，爆炸仍可触发炸药桶连锁；散弹八颗从4度窄束起步，0.25个游戏秒逐渐展开成48度扇形，瞄准只显示一条中心线，各自独立反弹与续能；首次反弹后保持反射方向，不再继续展开。飞行期间无法换弹，重试与切关保留已选弹种。

验证：`node check.cjs` 包括物理回归和全部关卡配额验证；`node campaign-check.cjs` 单独验证每关参考解、弹药、状态保留和错误顺序。`browser-check.cjs` 对本机 9410 端口的 Chrome 调试实例执行浏览器交互与响应式检查。
