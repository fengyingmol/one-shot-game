# 一发入魂 · 弹射小游戏

一个单手可玩的网页小游戏：拖动瞄准，松手开枪，用有限弹药、反弹和爆炸连锁清场。支持手机和电脑浏览器，包含十一关循序教学和一关综合挑战。

## 游戏内容与 AI 修改入口

完整规则、子弹与怪物、平衡参数、关卡和代码位置记录在 [游戏内容说明.md](游戏内容说明.md)。AI 修改项目先读 [AGENTS.md](AGENTS.md) 和这份说明；每次规则变化同步更新说明。

## 本地试玩

启动：`node server.cjs`，然后打开 http://127.0.0.1:4180 。也可以直接用浏览器打开 index.html。

在场地内拖动瞄准，松手开枪。每关只配发固定种类和数量的弹药，耗尽的弹种不能选。每一枪后保留怪物和地形的变化，自动进入下一枪；清场过关，用完弹药仍有怪则失败。R 重试整关，恢复弹药和场景。点击「关卡」展开选关，速度固定 800。声音默认关闭，可手动开启。

本地 UI 使用手绘「涂鸦训练场」：小人持枪随瞄准转向，场景略斜俯视有厚度，但弹道与碰撞仍保持平面坐标。手机优先显示场地、分数、本关弹药和重试；提示、元素及成绩可以展开查看。主题在 `casual.css`，图片和已附许可的图标在 `assets/`，无需在线 CDN。

手机高清优化：画布按显示尺寸和设备像素密度渲染（最高 3 倍密度），不改变物理坐标。手机文字和场地显示增大，发射 / 命中 / 得分增加轻量反馈；浏览器模拟 2x / 3x 手机画面及射击检查通过，实体手机性能仍需试玩。线上是否生效需核对部署结果。

上一枪轨迹默认隐藏。射击并重试后，可点击「查看上一枪轨迹」作为本次瞄准参考；每次重试恢复隐藏，切关清除轨迹。该按钮不是开关，不保留查看偏好。

每次有效命中 +10 分，同一枪内 1 个游戏秒内连续命中从第二次开始额外加 5、10、15……分；三连击合计 45 分。打掉头盔也计命中，盾牌挡弹和环境碰撞不加分。爆炸连锁击倒逐个计分。本关多枪累积分数，下一枪连击重新开始；重试整关清零，页面会话保留各关最高分。

三种内部地形：木色普通障碍物两次子弹命中或一次爆炸即可破坏；红褐色砖墙只能被爆炸破坏；蓝灰色铁墙不可破坏。未破坏时反弹，普通障碍物第二次命中后子弹直接穿过。爆炸弹碰到可破坏地形立即引爆并消失；破坏地形不加分、不续能，重试恢复。

采用 Canvas 图形，无外部依赖。每关独立房间大小：大部分教学关为宽 360–420、高 400–560，策略关 420 × 640；高速长路线与综合挑战保留 600 × 900。发射点和边界随房间改变。侧面和顶部反弹，底部开放，越过底部直接消失（爆炸弹落底也不引爆）。弹道保留 0.48 个游戏秒，基准速度 800，爆炸时短暂减速。

默认从第一关开始。教学顺序：穿透 → 铁墙反弹 → 头盔 → 两枪破障碍 → 爆炸开砖墙 → 盾牌背后 → 炸弹怪 → 桶连锁 → 高速长回程 → 散弹多方向 → 射击顺序。最后「四区回廊」有 18 只怪、4 个桶、3 种地形，配发普通 2 发、高速 / 爆炸 / 散弹各 1 发。侧栏按关卡记录成绩，刷新后清空。

测试关包含头盔怪和炸弹怪，各 4 只。头盔怪是戴金色头盔的普通怪：第一枪头盔翻滚掉落，不续能、不计击倒，子弹继续穿透；再次命中才击倒续能，爆炸可直接击倒。一次穿过不能连续扣两次生命，子弹离开后返回或另一颗弹丸命中才算下一枪。

炸弹怪为红色、带发光引线，一击死亡后产生半径 70 的小爆炸，计入清怪目标并续能；炸药桶不是怪物，不计清怪数，被子弹触碰或爆炸波及就引爆，半径 102。炸弹怪、炸药桶可以互相引爆，爆炸不伤害子弹。

瞄准前可选择四种子弹。动能比例为普通弹 1、高速弹 1.5、爆炸弹 0.8、散弹（每颗）0.5，比例与引擎实际能量分开配置。普通弹基础动能从旧版 2.4 降为 1.6，动能上限和命中续能也降低三分之一，再按弹种比例计算；飞行速度不变。

高速弹速度为普通弹的 1.5 倍；爆炸弹首次命中目标时产生一次半径 64 像素的爆炸，未命中则在耗尽时引爆，爆炸后子弹立即消失，爆炸仍可触发炸药桶连锁；散弹同时向八个方向发射，各自独立续能。飞行期间无法换弹，重试与切关保留已选弹种。

验证：`node check.cjs` 包括物理回归和全部关卡配额验证；`node campaign-check.cjs` 单独验证每关参考解、弹药、状态保留和错误顺序。`browser-check.cjs` 对本机 9410 端口的 Chrome 调试实例执行浏览器交互与响应式检查。

## GitHub Pages

这是无需构建的静态网站。GitHub 仓库中选择 Settings → Pages → Deploy from a branch，选择 `main` 分支和根目录 `/`，即可发布。线上入口为 `index.html`，需要同时包含 `style.css`、`casual.css`、`game.js` 与 `assets/`；`server.cjs` 与检查脚本仅供本地开发。仓库上传和线上部署是不同状态，线上是否更新需要单独核对部署结果。
