# 一发入魂 · 弹射小游戏

一个单手可玩的网页小游戏：拖动瞄准，松手开枪，用有限弹药、反弹和爆炸连锁清场。支持手机和电脑浏览器，可选十二关渐进正式关卡与三关测试挑战，独立教学关入口已取消。

## 游戏内容与 AI 修改入口

完整规则、子弹与怪物、平衡参数、关卡和代码位置记录在 [游戏内容说明.md](游戏内容说明.md)。AI 修改项目先读 [AGENTS.md](AGENTS.md) 和这份说明；每次规则变化同步更新说明。

音乐与音效：默认开启，点击进入游戏即启动播放，右上角设置内可静音并分别控制音乐与音效。原创《小院散步》为 96 BPM、40 秒轻松木琴 / 拨弦循环，14 种短音效区分射击、命中、反弹、护甲、地形、爆炸和胜负；「音乐与音效」面板可分别开关和调音量。切关不叠播，后台暂停，爆炸时音乐轻微避让。资源在 `assets/audio/`，用 `node make-audio.cjs` 可重建；`node audio-check.cjs` 验证音频。声音实现为 `soundtrack.js` + `audio.js`，随0.13一并提交。

每次有效命中 +10 分，同一枪内 1 个游戏秒内连续命中从第二次开始额外加 5、10、15……分；三连击合计 45 分。通关时未使用弹药按种类奖励：普通每发20分、穿甲30分、爆炸40分、散弹50分；散弹按库存发数计算。结算显示省弹奖励并计入最高分。打掉头盔也计命中，盾牌挡弹和环境碰撞不加分。爆炸连锁击倒逐个计分。通关按各关总分门槛评定1～3星，结算显示升级差分并可重试冲星；连击和省弹都能提高星级，各关最佳星级在本页面内保留。固定得分的机制教学完成即可三星。详细门槛见游戏内容说明0.46。本关多枪累积分数，下一枪连击重新开始；重试整关清零，页面会话保留各关最高分。

三种内部地形：木色普通障碍物两次子弹命中或一次爆炸即可破坏；红褐色砖墙只能被爆炸破坏；蓝灰色铁墙不可破坏。未破坏时反弹，普通障碍物第二次命中后子弹直接穿过。爆炸弹碰到可破坏地形立即引爆并消失；破坏地形不加分、不续能，重试恢复。

炸弹怪为红色、带发光引线，一击死亡后产生半径 70 的小爆炸，计入清怪目标并续能；炸药桶不是怪物，不计清怪数，被子弹触碰或爆炸波及就引爆，半径 102。炸弹怪、炸药桶可以互相引爆，爆炸不伤害子弹。

穿甲弹速度为普通弹的 1.5 倍，一击摧毁并穿透木障碍、一击击倒头盔怪，击倒只计一次命中并续能；砖墙、铁墙和盾牌仍反弹；爆炸弹首次命中目标时产生一次半径 64 像素的爆炸，未命中则在耗尽时引爆，爆炸后子弹立即消失，爆炸仍可触发炸药桶连锁；散弹八颗从4度窄束起步，0.25个游戏秒逐渐展开成48度扇形，瞄准只显示一条中心线，各自独立反弹与续能；首次反弹后保持反射方向，不再继续展开。飞行期间无法换弹，重试与切关保留已选弹种。
