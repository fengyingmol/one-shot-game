# 一发入魂 · 弹射小游戏

一个单手可玩的网页小游戏：拖动瞄准，松手开枪，用反弹和炸药桶连锁一枪清场。支持手机和电脑浏览器，含三个试玩关卡。

## 本地试玩

启动：`node server.cjs`，然后打开 http://127.0.0.1:4180 。也可以直接用浏览器打开 index.html。

在棋盘内拖动瞄准，松手开枪。小怪会给子弹续能；盾牌朝下，正面挡弹；炸药桶会连锁引爆。R 重试，右侧切换关卡和速度。声音默认关闭，可手动开启。

这是验证核心手感的三关原型，采用 Canvas 图形，无外部依赖。弹道保留 0.48 秒，子弹默认速度 800 像素/秒，一次射击最长 5.5 秒。爆炸时会短暂减速。

验证：`node check.cjs` 运行真实引擎的关卡可达性、盾牌、连锁爆炸、重试和过关检查。`browser-check.cjs` 对本机 9410 端口的 Chrome 调试实例执行浏览器交互与响应式检查。

## GitHub Pages

这是无需构建的静态网站。GitHub 仓库中选择 Settings → Pages → Deploy from a branch，选择 `main` 分支和根目录 `/`，即可发布。线上入口为 `index.html`，只需要 `style.css` 和 `game.js`；`server.cjs` 与检查脚本仅供本地开发。
